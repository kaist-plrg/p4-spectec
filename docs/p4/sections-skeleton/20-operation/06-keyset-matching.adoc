=== Keyset matching

// Added
Keyset matching tests whether a value belongs to a keyset. It is used both when
matching parser select cases and when matching table entries.

// Added
A tuple of keysets matches a tuple of values when each keyset matches its
corresponding value:

// Added
${func-source: match_keysets}
${func-prose: match_keysets}

// Added
A single keyset matches a value when the value is a member of the keyset's set:

// Added
${func-source: match_keyset}
${func-prose: match_keyset}
