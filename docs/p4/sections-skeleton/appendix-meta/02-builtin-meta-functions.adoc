== Built-in meta-functions

// Added
This appendix collects the built-in, low-level meta-functions on options,
sequences, sets, maps, and text that are used throughout the formal
specification. They are largely mechanical and are gathered here so that the
main specification remains readable.

=== Core notation and collections

// Added
A conditional chooses between two values:

// Added
${func-source: ite}
${func-prose: ite}

// Added
Options are inspected and converted to sequences with:

// Added
${func-source: is_some_}
${func-prose: is_some_}

// Added

${func-prose: opt_as_seq_}
