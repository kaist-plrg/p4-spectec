== Subexpressions

// Added
The immediate subexpressions of a typed expression, an expression, and an
argument are collected with:

${func-source: subexpressions_of_typedExpressionIR}
${func-prose: subexpressions_of_typedExpressionIR}

// Added
${func-source: subexpressions_of_typedExpressionListIR}
${func-prose: subexpressions_of_typedExpressionListIR}

// Added
${func-source: subexpressions_of_expressionIR}
${func-prose: subexpressions_of_expressionIR}

// Added
${func-source: subexpressions_of_argumentIR}
${func-prose: subexpressions_of_argumentIR}

// Added
${func-source: subexpressions_of_argumentListIR}
${func-prose: subexpressions_of_argumentListIR}
