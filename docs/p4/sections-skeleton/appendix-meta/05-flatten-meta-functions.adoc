== Flattening and unflattening

// Added
The surface grammar and P4~IR~ represent list-shaped constructs with recursive
productions. A right-recursive list associates to the right, so its head is the
first element and its tail is the remaining list; a left-recursive list
associates to the left, accumulating elements as it grows. To manipulate lists
uniformly, each recursive list is flattened into a sequence and later
reconstructed into its original left- or right-recursive shape by an
unflattening function. Unflattening a left-recursive list uses a primed helper
that carries an accumulator, and some constructs distinguish an empty from a
non-empty list.
