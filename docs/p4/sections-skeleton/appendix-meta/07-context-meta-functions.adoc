== Context and environment operations

// Added
This appendix collects the operations on the three contexts threaded through the
specification -- the typing, instantiation, and execution contexts -- and on the
environments they contain. Each context provides an empty value, operations to
add and look up bindings for the various kinds of entity it tracks, and
operations to enter and exit scopes.

=== Typing context

// Added
The typing context is threaded through type checking. It holds a stack of
scopes binding variables to their types, environments of type, callable-type,
and constructor-type definitions, and the type frame used for type-argument
inference. Its operations are suffixed with `_t`.

definitions available at instantiation time. Its operations are suffixed with

=== Execution context

// Added
The execution context holds the runtime information: the value environment, or
store, mapping variables to values, the object and architecture state, the
parser state, and the callable and constructor definition environments. Its
operations are suffixed with `_e`.
