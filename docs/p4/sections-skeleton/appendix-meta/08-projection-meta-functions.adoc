== Structural projections and identifiers

// Added
This appendix collects the projection functions that extract identifiers and
sub-structures -- such as parameter lists, type parameter lists, and signatures
-- from P4~IR~ definitions, types, and extern prototypes. These projections let
the specification treat the many kinds of callable and constructor uniformly.

[discrete]
==== Callable identifiers

// Added
The identifier of a callable is projected from a callable definition, a
callable type, and an extern method prototype with:

// Added
${func-source: callableId}
${func-prose: callableId}

// Added
${func-source: callableId'}
${func-prose: callableId'}

// Added
${func-source: callableId_IR}
${func-prose: callableId_IR}

// Added
${func-source: callableId_of_externConstructorPrototypeIR}
${func-prose: callableId_of_externConstructorPrototypeIR}

// Added
${func-source: callableId_of_externMethodPrototype}
${func-prose: callableId_of_externMethodPrototype}

// Added
${func-source: callableId_of_externMethodPrototypeIR}
${func-prose: callableId_of_externMethodPrototypeIR}
