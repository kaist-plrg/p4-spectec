=== Type argument inference

// Added
When a call omits some type arguments, they are inferred from the types of the
supplied arguments. The result of inference is an assignment of a type to each
type variable to be inferred:

// Added
${syntax: infer constraint inference}

// Added
${func-source: empty_constraint}
${func-latex: empty_constraint}
${func-prose: empty_constraint}

// Added
Type variables that are only used in `@optional` parameters are not strictly
inferred, while other type variables are strictly inferred, meaning they must
be determined by the arguments. The strictness of each type variable is
represented by:

// Added
${syntax: strict strictness}

// Added
${func-source: empty_strictness}
${func-latex: empty_strictness}
${func-prose: empty_strictness}

// Added
Inference generates constraints from each parameter and argument pair, merges
them, and resolves the merged constraint:

${func-prose: infer}

// Added

${func-prose: infer_pair}
