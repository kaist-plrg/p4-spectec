[#sec-cast]
== Casting

// 479 - Modified
P4 provides a limited set of casts between types. While this design is arguably
more onerous for programmers, it has several benefits:

// 480
* It makes user intent unambiguous.
* It makes the costs associated with converting numeric values
  explicit. Implementing certain casts involves sign extensions, and thus can
  require significant computational resources on some targets.
* It reduces the number of cases that have to be considered in the P4
  specification. Some targets may not support all casts.

[#sec-cast-chain]
=== Cast chains

// Added
A cast is not always a single step. Casting a sequence to a struct, for example,
casts each element of the sequence before casting the sequence as a whole, and
casting between two enums with an underlying type goes through that underlying
type. Checking a cast therefore yields the chain of types to cast through, in
order, or reports that no such cast exists.

// Added
${syntax: castResult}

// Added
The casts of the elements of an aggregate type are chained in lockstep, one cast
of the whole aggregate per step. An element whose chain is exhausted holds its
current type, so that all elements reach their target together.
