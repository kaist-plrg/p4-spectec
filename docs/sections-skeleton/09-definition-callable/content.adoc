== P4 callables

// Added
P4~16~ includes four entities that can be invoked: actions, functions, methods,
and object constructors. Object constructors are explained in
<<sec-def-object>>. The other three callable entities are collectively referred
to as *callables*.

During type checking, each callable is represented by their type:

${syntax: callableTypeIR}

The well-formedness rules for callable types are checked by:

[[CallableType_wf]]
${relation: CallableType_wf}

The runtime representation of a callable is given by:

${syntax: callableDef}
