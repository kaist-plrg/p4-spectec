[#sec-keyset-expression]
=== Keyset expressions

// Added
Keyset expressions are used to represent a set of values to be matched in
switch statements (<<sec-switch-statement>>) and parser select expressions
(<<sec-select-expression>>).

// Added
The following relation defines how keysets are evaluated:

// Added
${relation-title-source: Expr_eval_keyset}
${relation-title-prose: Expr_eval_keyset}

// Added
The result of evaluating a keyset expression is:

// Added
${syntax: keysetExpressionResult}

// Added
The relation works as follows:

// Added
${rulegroup-source: Expr_eval_keyset}
${rulegroup-prose: Expr_eval_keyset}

// Added
It decomposes the `keysetExpressionIR` into ``simpleKeysetExpressionIR``s,
evaluates each of those, and then combines the results into a single
`keysetExpressionResult`.

// Added
The ``simpleKeysetExpressionIR``s are evaluated as follows:

// Added
${relation-title-source: Exprs_eval_keyset_simple}
${relation-title-prose: Exprs_eval_keyset_simple}

// Added
${rulegroup-source: Exprs_eval_keyset_simple}
${rulegroup-prose: Exprs_eval_keyset_simple}

// Added
A `simpleKeysetExpressionIR` is evaluated as follows:

// Added
${relation-title-source: Expr_eval_keyset_simple}
${relation-title-prose: Expr_eval_keyset_simple}

// Added
The result of evaluating a `simpleKeysetExpressionIR` is:

// Added
${syntax: simpleKeysetExpressionResult}
