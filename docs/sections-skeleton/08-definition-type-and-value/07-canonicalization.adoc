=== Canonicalization

${syntax: typedefTypeIR specializedTypeIR}

``typedef``s and specialized types introduce indirection in types.

[source,p4]
----
struct S<T, U> {
    T t;
    U u;
}

typedef S<int<32>, bit<32>> A;
----

The type ``A`` is an alias of the struct type ``S<int<32>, bit<32>>``. The
struct type is again, a `specialiedTypeIR`, where it specializes a polymorphic
type definition for the generic struct ``S`` with the type arguments
``int<32>`` and ``bit<32>``.

Neverthelss, the underlying type of ``A`` is a `structTypeIR` with two fields,
``t`` and ``u``, of types ``int<32>`` and ``bit<32>`` respectively. It is
useful to be able to work with the underlying type of ``A``, when dealing with
type checking, type equivalence, and other type-based analyses.

Canonicalization is the process of recursively specializing types and unrolling
typedefs until a type is fully expanded.
