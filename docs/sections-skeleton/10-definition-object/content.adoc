== P4 objects

``table``s and ``extern`` objects are stateful entities in P4 programs. These
objects should be instantiated statically prior to program execution.
``parser``s, ``control``s, and ``package``s may contain stateful objects,
thus they must also be instantiated.

The runtime representation of these objects is defined as follows:

${syntax: object}

The instantiation phase creates objects in the source P4 program, and
allocates them in the global store. At runtime, these objects interact, as
defined by the target architecture, to process packets.
