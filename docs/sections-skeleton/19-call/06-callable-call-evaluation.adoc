=== Callable calls

// Added
Callable calls are type checked as follows:

// Added
${relation-title-source: Call_ok}
${relation-title-prose: Call_ok}

// Added
At runtime, callable callees are evaluated as follows:

// Added
${relation-title-source: Call_eval}
${relation-title-prose: Call_eval}

// Added
The following subsections describe the type checking and evaluation of callable
calls for different types of callees.
