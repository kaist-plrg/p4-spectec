[#sec-call]
== Calls

// Added
Calls can be made in several different contexts:

// Added
* From call expressions (<<sec-call-expression>>), to invoke a callable or a
  constructor.
* From call statements (<<sec-call-statement>>), to invoke a callable.
* From a direct type invocation (<<sec-direct-type-invocation>>), which is a
  syntactic sugar for invoking a constructor and then immediately calling an
  apply method on the resulting instance.
* From an instantiation declaration (<<sec-instantiation-declaration>>), to
  invoke a constructor.

// Added
