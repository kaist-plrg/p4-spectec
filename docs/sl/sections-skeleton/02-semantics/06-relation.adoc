=== Relations

Relation calls are dispatched through the same layered chain as function calls:
the relation definition is resolved from the context, then evaluation is
dispatched based on whether the relation is extern or user-defined.

An entry point for relation calls is the following relation:

${relation-title-prose: Call_rel}
${rulegroup-prose: Call_rel}

The actual function call is performed by the following relation, dispatching
according to the function type. The relation definition is looked up in the
context and its kind determines which evaluation strategy is used.

${relation-title-prose: Call_rel_dispatch}
${rulegroup-prose: Call_rel_dispatch}

==== Extern relations

Extern relations are declared in the specification but implemented outside of
it, typically by the host environment or an architecture-specific model. The
specification defines only the signature; the implementation is invoked by the
interpreter's external dispatch mechanism.

${relation-title-prose: Call_extern_rel}

==== User-defined relations

A user-defined relation in the structured language is defined by a primary
block and an optional else block, together with input pattern expressions
embedded in the definition. Calling a user-defined relation creates a fresh
local context, assigns the actual input values to the definition's input
expression patterns, and then evaluates the combined block. The relation's
outputs are extracted from a `RES val*` flow produced by a `RESULT` instruction
within the block.
