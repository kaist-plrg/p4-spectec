=== Context

A context holds the environments used for evaluation. It is consisted of two
layers, global and local, each holding four environments for values, types,
functions, and relations.

${syntax: context layer}
${syntax: tdenv renv fenv venv}

==== Loading a context

Before evaluation, a context must be loaded from the specification script.

${func-prose: load}

${func-prose: load_typdef}

${func-prose: load_reldef}

${func-prose: load_funcdef}

==== Creating sub-contexts for iteration

When evaluating iteration (via `?` or `*`), sub-contexts are created for each
dimension being iterated over.

${func-prose: sub_opt}

${func-prose: sub_list}

${func-prose: sub_list'}
