== P4 types and values

P4~16~ supports a variety of types and values. This section describes the basic
types and values, as well as the more complex types and values that can be
constructed from them.

The syntax for P4 types is as follows:

${syntax: type
          typeOrVoid}

These types are represented internally in P4~IR~ as follows:

${syntax: typeIR}

The types represent the kinds of values that can be used in P4 programs. The
runtime representation of P4 values is as follows:

${syntax: value}
